# Campus Library Management System
A simple console-based Java program to manage book cataloging and borrowing operations for a campus library. Developed to demonstrate clean code organization and core OOP design patterns.
## Features
- **Catalog Overview:** List all books with real-time status (Available / Checked Out).
- **Borrow & Return:** Update book availability with built-in validation checks.
- **Console Interface:** Clean menu navigation using Java's enhanced switch expressions.
- **Modular Structure:** Separated model logic, library service, and main application setup.
## Tech Stack
- **Language:** Java 17+
- **IDE:** IntelliJ IDEA
- **Concepts:** Object-Oriented Programming (OOP), Java Collections (`ArrayList`), Clean Code Architecture
## How to Run
1. Clone or download the repository.
2. Open the project in **IntelliJ IDEA**.
3. Run `Main.java` from the `src` folder.
